# Tarea 2 - Desarrollo Web

Contiene todos los archivos para correr la aplicación web de la tarea, primero se deberan descargar las librerias necesarias para la ejecución de la aplicación. Para ello se deberá ejecutar la instrucción:

```bash
    pip install -r requirements.txt
```

Luego se deberá ejecutar la instrucción:

```bash
    python run.py
```

Este comando generará una dirección que se deberá colocar en algun navegador y se podrá ver la página
