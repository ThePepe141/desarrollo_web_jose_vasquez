# Tarea 2 - Desarrollo Web

Contiene todos los archivos para correr la aplicación web de la tarea, primero se deberan descargar las librerias necesarias para la ejecución de la aplicación. Para ello ejecute dentro de su ambiente la instrucción:

```bash
    pip install -r requirements.txt
```

Luego ejecute la instrucción:

```bash
    python run.py
```
